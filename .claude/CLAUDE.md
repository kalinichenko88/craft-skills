# craft-skills

Before a spec, a plan or the first edit of a new feature, read
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md). At the start of a new feature,
and for a decision, load `craft:architecture`.

In this repository, a defect in the plugin is an out-of-scope finding like
any other: *Out-of-scope findings become issues* in `rules.md` applies to it,
not *A defect in this plugin goes to its tracker*, so do not ask before you
file it.
